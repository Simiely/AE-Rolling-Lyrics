# AE-Rolling-Lyrics · 滚动歌词生成器

AE 2026 脚本（ExtendScript）：把整段歌词自动拆成逐句图层，做**卡拉 OK 式滚动歌词**——滚动到画面中心的一句放大 + 100% 透明度，未到中心保持普通字号 + 指定透明度，间距恒定。

## 功能特性

- **自动拆分**：粘贴整段歌词（每句一行）或选中文本图层，自动按句拆分，数量自适应
- **中心高亮**：滚动到中心的一句放大到「最大字号」、100% 透明度；其余保持「普通字号」+ 普通透明度
- **等间距滚动**：偏移量自动等差，间距恒定；滚动帧数 / 停顿帧数可调
- **参数控件化**：9 个参数（最大字号、普通字号、间距、最大透明度、普通透明度、滚动帧数、停顿帧数、停顿随机开关、抖动帧数）以效果控件挂在 `Lyrics_Ctrl` 上——生成后选中空对象，在效果控件面板直接改数值即实时生效，无需重新生成
- **停顿随机**：开启后每句实际停顿 = 停顿帧数 ± 抖动帧数（如 30±10 → 20~40 随机），每句固定不闪烁，改控件实时生效
- **整体移动**：拖动 `Lyrics_Master` 空对象可整体移动歌词，放大高亮跟随移动（预合成式效果）
- **预设存储**：4 个槽位，双层持久化（工程目录 JSON + AE 全局设置保底）
- **超长句自适应**：超出画布宽度的歌词自动缩字号，防止溢出（AE 内调大字号也不会溢出）
- **Debug 模式**：报错弹出可复制对话框（Ctrl+A / Ctrl+C），便于排查

## 安装

1. 复制 `rolling-lyrics.jsx` 到：
   `%APPDATA%\Adobe\After Effects\26.0\Scripts\ScriptUI Panels\`
2. **重启 After Effects**（面板在启动时扫描）

## 快速开始

1. 菜单 **Window > 扩展 > rolling-lyrics.jsx** 打开面板
2. 在「歌词」输入框粘贴整段歌词（每句一行，回车分隔）——或选中含歌词的文本图层
3. 调整参数（最大/普通字号、间距、透明度、滚动/停顿帧数）
4. 点击「生成滚动歌词」
5. **实时微调**：选中 `Lyrics_Ctrl` 空对象，在效果控件面板里改任意参数（最大字号 / 普通字号 / 间距 / 最大透明度 / 普通透明度 / 滚动帧数 / 停顿帧数 / 停顿随机 / 抖动帧数）——全部实时生效，无需重新生成

## 图层结构

| 图层 | 作用 |
|---|---|
| `Lyrics_Master` | 总控制：拖动整体移动歌词 |
| `Lyrics_Ctrl` | 滚动控制：驱动滚动节奏，**挂 9 个参数控件**（中文名，实时可调） |
| `歌词_1 ~ 歌词_N` | 每句歌词，挂位置/缩放/透明度表达式（引用控件） |

> 提示：`scrollFrames` / `pauseFrames` 调大后若超出合成时长，手动拖长合成即可；改 `gap` / `maxSize` 等视觉参数不会超出时长限制。

重跑脚本会自动清理旧的生成图层。

## 预设管理

- **存储 1-4**：把当前参数存进槽位（工程目录 `滚动歌词预设.json` + 全局设置双写）
- **使用 1-4**：一键载入预设
- **复位**：恢复默认参数
